# Code of conduct

This project is for people who run and build tools that touch other people's servers. We want it to be a calm, useful place to ask questions, report problems and send changes.

## What we expect

- Be respectful. Disagree about the code, not about the person.
- Assume good faith, and say what you mean plainly.
- Be patient with newcomers and with people for whom English is not a first language.
- Give and accept feedback on pull requests as a way to improve the change.

## What is not acceptable

- Harassment, insults, threats or discrimination of any kind.
- Publishing someone else's private information, including server details, tokens or credentials.
- Spam, or using issues and pull requests to promote unrelated things.

## Security reports

Security problems are not conduct matters. Do not post them in public; follow [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may edit or remove comments, close or lock issues and pull requests, and block people who break these rules. To report a conduct problem, use the repository's **Security** tab ("Report a vulnerability") and say that it is a conduct report, so that it stays private. We will look into it and answer.

## Scope

This applies to the repository, its issues, pull requests and discussions.
